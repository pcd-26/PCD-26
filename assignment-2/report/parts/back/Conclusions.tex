\section{Conclusions}

Assignment 2 delivers a compact asynchronous filesystem statistics library
with three distinct execution styles. The main result is that the same report
can be computed cleanly through three genuinely different concurrency models:
task-oriented recursion with virtual threads, stream composition with RxJava,
and callback-driven asynchronous I/O with Vert.x.

The codebase keeps the report model and the filesystem logic separate from the
execution strategy, which makes the three implementations directly comparable
without blurring their programming style. The optional interactive part is
covered by the Swing GUI, and the validation suite confirms that the engines
agree on deterministic datasets while remaining robust under common filesystem
edge cases.
