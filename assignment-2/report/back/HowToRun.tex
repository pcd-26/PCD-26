\section{How to Run}

\textbf{Prerequisites:} Java 21 and Maven.

\subsection{Tests}

From the directory generated by the CI, run the full validation suite with:

\begin{verbatim}
mvn -f pom.xml test
\end{verbatim}

\subsection{CLI}

The CLI entry point is \texttt{pcd.fsstat.cli.FSStatCLI}, implemented in
\texttt{src/main/java/pcd/fsstat/cli/FSStatCLI.java}. The arguments are:

\begin{verbatim}
<directory> <maximumFileSize> <numberOfBands> [sizeUnit] [paradigm]
\end{verbatim}

The last argument selects the implementation: \texttt{vt}, \texttt{rx}, or
\texttt{loop}.

From the same directory:

\small
\begin{verbatim}
mvn -f pom.xml exec:java "-Dexec.mainClass=pcd.fsstat.cli.FSStatCLI" "-Dexec.args=. 10 5 MiB vt"
\end{verbatim}
\normalsize

Replace \texttt{vt} with \texttt{rx} or \texttt{loop} to run the other
implementations.

\subsection{GUI}

The Swing entry point is \texttt{pcd.fsstat.gui.FSStatGUI}, implemented in
\texttt{src/main/java/pcd/fsstat/gui/FSStatGUI.java}.

\small
\begin{verbatim}
mvn -f pom.xml exec:java "-Dexec.mainClass=pcd.fsstat.gui.FSStatGUI"
\end{verbatim}
\normalsize

The GUI exposes the same scan parameters as the CLI and adds start and cancel
controls.
