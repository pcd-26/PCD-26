\section{Introduction and Problem Analysis}

This report describes the \textbf{Smart Home Alarm System}, implemented in Java with \textbf{Apache Pekko Typed}.
The system receives events from a keypad and from a small sensor network, then changes the alarm state according to the
current mode of operation.

The Smart Home Alarm System is a reactive concurrent system.
Its inputs come from independent sources: the \textbf{keypad}, the \textbf{motion sensors}, and the
\textbf{door/window sensors}.
The controller must process those inputs according to the current alarm state, while also reacting to timeout events
generated by the exit and entry delays.

The alarm controller has five states:
\begin{itemize}
    \item \textbf{DISARMED}: sensor activations are logged but cannot trigger the alarm;
    \item \textbf{EXIT\_DELAY}: the user has entered a valid PIN and can leave the house;
    \item \textbf{ARMED}: sensors in active zones can start the entry delay;
    \item \textbf{ENTRY\_DELAY}: the user can still disarm the system before the siren starts;
    \item \textbf{ALARM}: the siren is active until the correct PIN is submitted.
\end{itemize}

The main concurrency issue is \textbf{serialization of state transitions}.
Sensor events, PIN submissions, and timer expirations can be produced independently, but the alarm state must evolve in
one well-defined order.
For this reason the design gives exclusive ownership of the state machine to the \textbf{control unit actor}.
All other actors interact with it by sending messages.

The assignment also includes timed behavior.
The \textbf{exit delay} postpones the transition to \textit{ARMED}, so sensors are still ignored while the user is leaving.
The \textbf{entry delay} postpones the transition to \textit{ALARM}, so a valid PIN can still avoid the emergency state.
Both delays are modeled as messages sent to the control unit after a configurable duration.

The optional zone-based extension is implemented with a fixed set of domain zones.
During arming, the user can request either \textbf{full arming}, which activates every zone, or \textbf{partial arming},
which activates only the selected zones.
A sensor can start the entry delay only if its zone is currently armed.
