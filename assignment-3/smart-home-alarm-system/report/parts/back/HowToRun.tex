\section{How to Run}

\begin{itemize}[leftmargin=*]
  \item Build: \texttt{mvn -f assignment-3/smart-home-alarm-system/pom.xml compile}
  \item Test: \texttt{mvn -f assignment-3/smart-home-alarm-system/pom.xml test}
  \item Demo: \texttt{mvn -f assignment-3/smart-home-alarm-system/pom.xml exec:java}
\end{itemize}

The demo scenario is intentionally short so it can be used as a smoke test and as a quick manual validation of the
alarm flow.
