\section{How to Run}

\begin{itemize}
  \item Build and test: \texttt{go test ./...} from the \texttt{src} directory
  \item Run the race detector: \texttt{go test -race ./...}
  \item Run: \texttt{go run . -players 8}
  \item Input rule: the CLI accepts only positive powers of two.
\end{itemize}

The fixed tossers used in the tests make the execution reproducible while still exercising the concurrent scheduling of
the round workers.
