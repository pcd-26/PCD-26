\section{Complexity}

The tournament performs exactly $N - 1$ matches for $N$ players.
So the total work of the algorithm is linear in the number of players, $O(N)$.

The number of rounds is $\log_2 N$, so the critical path is logarithmic in the number of players.
That is the part that matters when rounds are executed sequentially but matches inside each round are parallel.

The amount of live concurrency is bounded by the size of the current round.
In the first round there are $N/2$ match workers, then $N/4$, and so on until the final.
So the peak parallelism is $O(N)$, while the span remains $O(\log N)$.

This is a good trade-off for the assignment because the parallelism is concentrated exactly where it is useful: inside each
round, not across dependent rounds.
