\section{How to Run}

From the \texttt{assignment-3/odds-and-evens-game/src} directory:

\begin{itemize}
  \item Test: \texttt{go test ./...}
  \item Race detector: \texttt{go test -race ./...}
  \item Run: \texttt{go run . -players 8}
\end{itemize}

The \textbf{CLI} accepts only positive powers of two for the number of players.

The tests use \textbf{deterministic} toss functions, so the execution is reproducible while the concurrent scheduling of
the round workers is still exercised.
