\section{How to Run}

The delivery requires \textbf{JDK 17} and \textbf{Maven}. After extracting
\texttt{Assignment-01.zip}, enter the \texttt{Assignment-01} directory. Its
\texttt{pom.xml} builds the supplied production and test sources.

\textbf{Build and run all tests}
\begin{verbatim}
mvn clean test
\end{verbatim}

\textbf{Compile the application}
\begin{verbatim}
mvn compile
\end{verbatim}

\textbf{Start the sequential launcher}
\begin{verbatim}
java -cp target/classes pcd.poool.SequentialPoool
\end{verbatim}

\textbf{Start the platform-thread launcher}
\begin{verbatim}
java -cp target/classes pcd.poool.ThreadedPoool
\end{verbatim}

\textbf{Start the task-based launcher}
\begin{verbatim}
java -cp target/classes pcd.poool.TaskBasedPoool
\end{verbatim}

A positive argument optionally selects the task-based physics worker count.
\begin{verbatim}
java -cp target/classes pcd.poool.TaskBasedPoool 8
\end{verbatim}

The human shot can be aimed with the arrow keys or by dragging the mouse and is
released automatically or on mouse release. Press \texttt{R} to restart; after
game over, the \texttt{New Game} button provides the same action.
