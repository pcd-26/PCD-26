\section{Conclusions}

The project implements sequential, platform-thread, and task-based versions of
\emph{Poool} without duplicating game rules. The key design choice is a
single-writer controller that orders commands, advances the model, and
publishes only completed snapshots, while the physics step may internally use
parallel workers on disjoint board data under exclusive board ownership.

The benchmarks show a measurable but sublinear benefit from concurrency. On the
largest tested workload, the threaded engine reaches $2.342\times$ speedup and
the task-based engine reaches $2.109\times$; both saturate around 8 workers.
JUnit tests validate the production code, while JPF verifies the reduced
synchronization protocol. Together, these results support the adopted approach:
parallelize independent physics work while keeping state transitions explicit
and deterministic.
