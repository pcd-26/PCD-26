\section{Introduction}

Assignment 1 requires two concurrent versions of \emph{Poool}: one based on
platform threads and one based on the Executor framework. We also keep a
sequential version as correctness and performance baseline.

The three implementations share the same game rules, board representation, and
graphical view. They differ only in the execution strategy used to advance the
simulation and parallelize the physics step.

The report discusses the project from a concurrent perspective, presenting the
adopted architecture, the main implementation decisions, the verification
approach based on JPF, and the performance evaluation against the sequential
baseline.
