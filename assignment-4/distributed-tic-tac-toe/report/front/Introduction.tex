\section{Introduction}

This project implements the \textbf{distributed Tic-Tac-Toe system} required by
the second part of Assignment 4. One player can create a named room and
another player can join it later, with all distributed interactions carried out
through \textbf{Java RMI remote objects}.

Although Tic-Tac-Toe is a simple game, the distributed version introduces
\textbf{remote discovery}, \textbf{concurrent client requests}, and
\textbf{asynchronous state propagation}. The main problem is therefore not the
game rules themselves, but the correct coordination of players and match
state.
