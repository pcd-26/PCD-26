\section{How to Run}

This section describes a minimal \textbf{Windows PowerShell} execution
scenario with \textbf{1 registry}, \textbf{1 server}, and \textbf{2 clients}.
All commands assume the current directory is
\texttt{assignment-4/distributed-tic-tac-toe}.

\subsection{Build}

Compile the project sources:

\begin{lstlisting}[style=codestyle]
mvn clean compile
\end{lstlisting}

\subsection{Terminal 1: Registry}

Start the RMI registry on the default port:

\begin{lstlisting}[style=codestyle]
mvn exec:java "-Dexec.mainClass=pcd.dttt.Main" "-Dexec.args=registry 1099"
\end{lstlisting}

\subsection{Terminal 2: Server}

Start the server and bind the lobby service under the default name
\texttt{Lobby}:

\begin{lstlisting}[style=codestyle]
mvn exec:java "-Dexec.mainClass=pcd.dttt.Main" "-Dexec.args=server localhost 1099 Lobby"
\end{lstlisting}

\subsection{Terminal 3: Client 1}

Start the first client. This player can create a room.

\begin{lstlisting}[style=codestyle]
mvn exec:java "-Dexec.mainClass=pcd.dttt.Main" "-Dexec.args=client localhost 1099 Lobby"
\end{lstlisting}

If a command-line client is preferred, use:

\begin{lstlisting}[style=codestyle]
mvn exec:java "-Dexec.mainClass=pcd.dttt.Main" "-Dexec.args=client localhost 1099 Lobby --cli"
\end{lstlisting}

\subsection{Terminal 4: Client 2}

Start the second client with the same registry host, port, and service name:

\begin{lstlisting}[style=codestyle]
mvn exec:java "-Dexec.mainClass=pcd.dttt.Main" "-Dexec.args=client localhost 1099 Lobby"
\end{lstlisting}

\subsection{Minimal execution flow}

\begin{enumerate}
    \item Start the \textbf{registry}.
    \item Start the \textbf{server}.
    \item Start \textbf{client 1} and create a room with a chosen name.
    \item Start \textbf{client 2} and join that room using the same name.
    \item Play the match until win, draw, or abandonment.
\end{enumerate}

This setup is enough to exercise the full distributed path:
\textbf{registry lookup}, \textbf{server binding}, \textbf{room creation},
\textbf{room join}, and \textbf{callback-driven state propagation}.
